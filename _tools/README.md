# أدوات تقرير حريق مبنى 2

| الملف | الوظيفة |
|---|---|
| `admin-source.html` | نسخة مطابقة من لوحة الإدارة (المصدر الذي يُبنى منه التقرير) |
| `build.js` | يبني التقرير من لقطة البيانات ويكتب `b2-7f3a9c2e/index.html` + نسخة الـ Artifact |
| `similar.js` | كشف المهام المتشابهة (اقتراح فقط — لا دمج ولا حذف) |

## التحديث
```
node _tools/build.js <مجلد اللقطة> [مجلد الإخراج]
```
مجلد اللقطة = ناتج ArtifactData (`list` مع `out_dir`) لمجموعتي `tasks` و`meta`.

## قاعدة
أي تعديل على تصميم لوحة الإدارة يُنسخ إلى `admin-source.html` في نفس الـ commit،
وإلا رجع التقرير للتصميم القديم في التحديث التالي.

سجل git لهذا المستودع = سجل زمني لكل تحديث على التقرير (مفيد للتوثيق).
