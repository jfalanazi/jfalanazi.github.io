# ورد التدبر

تطبيق ويب لحفظ جزء عمّ وفهمه — يعمل بدون إنترنت، ويُثبَّت على الجوال كتطبيق.

## ما الذي يفعله

يفتح على **درس اليوم محدّدًا سلفًا** ويمشّيك على خمس خطوات:

| الخطوة | المحتوى |
|---|---|
| تدبّر | محور السورة، سبب النزول، المعنى والبناء — الفهم قبل الحفظ |
| قراءة تصويرية | النص في إطار ثابت مع مؤقّت ٦٠ ثانية، قراءة بالعين بلا صوت |
| استحضار | إخفاء تدريجي على ثلاثة مستويات، تُكشف الآية بالضغط عليها |
| متشابهات وتجويد | المواضع المشتبهة مع ضابط التمييز، وملاحظة أداء عملية |
| الربط والتطبيق | ربط آخر آية بأول آية في الدرس القادم، وأسئلة تدبّر |

ثم تقيّم إتقانك من ١ إلى ٥، فيُجدول المقطع في **نظام التكرار المتباعد**
(١ ← ٣ ← ٧ ← ١٥ ← ٣٠ ← ٦٠ ← ١٢٠ يومًا). الإتقان العالي يباعد المراجعة،
والمتعثّر يُعيدها إلى الغد. والمراجعات المستحقّة تُعرض قبل الدرس الجديد تلقائيًا.

## المحتوى

- **جزء عمّ كاملًا**: ٣٧ سورة، ٥٦٤ آية، مقسّمة إلى **٦٩ درسًا** بمعدّل ١٥–٢٠ دقيقة للدرس.
- **محتوى معلّم لكل سورة**: المحور، المعنى والبناء، سبب النزول حيث ثبت، ملاحظة تجويد عملية، وسؤالا تدبّر.
- **١٦ موضعًا من المتشابهات** مع ضابط التمييز لكل موضع. تُخزَّن كمراجع آيات لا كنص منسوخ،
  والفروق تُحسب وتُميَّز تلقائيًا بمقارنة الكلمات بعد تجريد التشكيل.

## «اسأل معلّمي»

خاصية اختيارية: تضيف مفتاح Anthropic API في الإعداد فتستطيع سؤال أي شيء عن المقطع الذي تدرسه.
المفتاح يُحفظ في متصفّح جهازك وحده ولا يمرّ بأي خادم وسيط. بقيّة محتوى المعلّم يعمل بدون مفتاح وبدون إنترنت.

## التثبيت على الجوال

- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتحه في Chrome ← القائمة ← «تثبيت التطبيق».

بعد أول فتح يعمل التطبيق كاملًا بدون إنترنت: النصوص والخطوط والمحتوى تُخزَّن كلّها في جهازك.

## التقدّم والخصوصية

تقدّمك يُحفظ في متصفّح جهازك (`localStorage`) ولا يُرسل إلى أي جهة.
لذلك استخدم **تصدير تقدّمي** في الإعداد قبل تغيير الجهاز أو مسح بيانات المتصفّح.
